# Application Screenshots

Add the real application screenshots here using these filenames:

- `dashboard.png` — Main application dashboard (inputs and header)
- `analysis-results.png` — Candidate assessment profile, ATS score, and summary
- `skill-analysis.png` — Verified strengths, skill gaps, and visual analytics
- `report.png` — Downloaded PDF assessment report preview

### How to Upload Screenshots via GitHub

1. Navigate to `assets/screenshots/` in your repository on GitHub.
2. Click **Add file** $\rightarrow$ **Upload files**.
3. Drag and drop your screenshots using the exact filenames listed above.
4. Commit the changes to `main`.
5. The `README.md` and `DEMO.md` files will automatically display the images using relative paths.
